📊 Actuarial Exam FM - Sample Practice Questions

Test your knowledge with this timed practice exam. All questions include detailed explanations with LaTeX formulas.

📝 How to Use in Your Obsidian Notes

To add this exam simulator to any Obsidian note (which will be rendered by Quartz), simply paste this HTML structure:

<!-- Exam Simulator Container -->
<div id="exam-simulator" data-timer="120">
  <!-- Quiz UI will be injected here -->
</div>

<!-- Quiz Data (JSON) -->
<script id="quiz-data" type="application/json">
[
  {
    "id": "unique-question-id",
    "question": "Your question with $\\LaTeX$ support",
    "options": [
      "Option A with $\\frac{1}{2}$",
      "Option B",
      "Option C",
      "Option D"
    ],
    "correctIndex": 0,
    "explanation": "Detailed explanation with formulas: $E = mc^2$"
  }
]
</script>

Important Notes:

  • data-timer: Set the exam duration in minutes
  • LaTeX Support: Use single dollar signs $...$ for inline math and double $$...$$ for display math
  • HTML in Questions: You can use <br>, <ul>, <li>, etc. for formatting
  • correctIndex: Zero-indexed (0 = first option, 1 = second, etc.)
  • MathJax Rendering: The script automatically calls window.MathJax.typesetPromise() after each navigation
